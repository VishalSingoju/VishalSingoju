## 👨‍💼 About Me

I build AI products for finance. **FinRAG** lets anyone upload a 300-page annual report and get a sourced answer to "what was net profit?" in seconds, with the exact PDF pages cited so nothing has to be taken on trust.

B.Tech graduate working at the line where machine learning meets banking, financial services and insurance. I care about retrieval quality, verifiable answers and products that are live on a URL, not stuck in a notebook.

Away from the keyboard I run **Vishal's Shutter Stories**, a photography practice covering weddings, portraits and wildlife.

<br/>

## 🚀 What I Do

| Project | Problem it solves | Proof points |
|:--|:--|:--|
| 📊 [**FinRAG**](https://github.com/VishalSingoju/FinRAG) | Finding one number in a 300-page annual report | Live on Streamlit, answers cite source pages, top-5 semantic retrieval, Dockerized |
| 🫁 [**Pneumonia-Detection**](https://github.com/VishalSingoju/Pneumonia-Detection) | Screening chest X-rays for pneumonia | CNN in TensorFlow/Keras, trained on the Kaggle chest X-ray set, 32 commits, Streamlit UI |
| 🎞️ [**ReelVault**](https://github.com/VishalSingoju/ReelVault) | Saved reels you never find again | Share-sheet PWA, Claude summarizes and tags each save, auto-groups by topic |
| 💀 [**Broke Or Not**](https://github.com/VishalSingoju/Broke_Or_Not) | Expense tracking nobody sticks with | Flutter + Hive, fully offline, multi-account balances, debt tracker, INR support |
| 📸 [**Shutter Stories**](https://vishalsshutterstories.vercel.app) | A photography business with no web presence | 6-page static site, lightbox galleries, responsive from 375px, deployed on Vercel |
| ✍️ [**ASD-STE100-skill**](https://github.com/VishalSingoju/ASD-STE100-skill) | Ambiguous technical writing | Claude skill with a rules reference and a heuristic checker script |

**Currently:** deepening RAG quality (hybrid search, reranking, evaluation) and extending FinRAG to multi-report comparison and financial ratios.
